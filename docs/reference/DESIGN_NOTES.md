# Референс: Spotify-клиент в MD3 Expressive

Источник: `video_2026-10-09_19-31-48.mp4` (55 с, 1776×1080).
Кадры: `screens/NNN.png` (смена сцены), раскадровки переходов: `motion/*.png`.

Стиль — **Material 3 Expressive** (2025): морфинг фигур, «печеньки», волнистый прогресс, толстые слайдеры, группы кнопок.

## Главное окно (`screens/000.png`, `015.png`)

- Тёмная тема. Сайдбар на чистом чёрном; контент и правая панель — отдельные «плавающие» скруглённые контейнеры (radius ≈ 24) с зазором ~8 px.
- **Сайдбар**: Home / Search; выбранный пункт — пилюля во всю ширину (surface-container-high), иконка в квадратике цвета primary. Заголовки секций (`Library`, `Playlists`) — мелкий label + **волнистый разделитель** до края, справа действие `+`. Сворачиваемые «Pinned Playlists», плейлисты с миниатюрами и индикатором «скачано». Внизу карточка аккаунта (аватар, имя, статус, `…`).
- **Верхняя панель контента**: назад, поиск-пилюля по центру (обводка primary в фокусе, кнопка очистки), overflow-меню. На странице плейлиста — иконки действий (+, edit, share, …, sort) и «Find in playlist».
- **Строка трека**: обложка ~48 px (radius ~6), название (primary, если играет), подзаголовок «Артист — Альбом» приглушённо, бейдж E, звезда-лайк, `…`, длительность. Играющая строка — лёгкая заливка primary с низкой непрозрачностью.
- **Мини-плеер**: плавающая пилюля внизу контент-панели. Shuffle, prev, **play/pause в залитой primary «печеньке»**, next, repeat | обложка, название, артист, тонкий прогресс | `…`, визуализатор, текст (активен = primary), очередь, громкость.
- **Правая панель**: текст песни, крупный жирный приглушённый шрифт.
- Акцент главного окна — статичный зелёный (primary). Dynamic color из обложки работает только в Now Playing.

## Переход в Now Playing (`motion/open_nowplaying*.png`)

- Из обложки мини-плеера вырастает **морфящийся блоб** («цветок» с 6–8 лепестками → неправильный многоугольник → весь экран), внутри него уже размытый фон Now Playing. Длительность ≈ 0.5–0.6 с, emphasized easing.
- Обложка «приземляется» в позицию большой обложки; закрытие — обратная анимация.

## Now Playing (`screens/004.png`, `006.png`, `017.png`)

- **Фон**: сильно размытая увеличенная обложка + тёмная вуаль; медленно «течёт».
- Сверху слева — круглая кнопка ✕. Справа — **группа иконок-кнопок в пилюле**: мини-режим, текст (выбран = белая пилюля), очередь, таймер сна, настройки.
- **Левая колонка**:
  - Обложка — квадрат (radius ~16) или круг в форме **cookie** (скалопированный край); за ней пульсирующий блоб цвета обложки, вокруг — опционально круговой визуализатор.
  - Название (жирное, крупное, обрезка «…»), артист + `…`, альбом мелко.
  - Прогресс: прошло / −осталось; **волнистый (squiggly) прогресс** на проигранной части во время воспроизведения, прямой на паузе.
  - Кнопки: shuffle (активен = тональный квадрат), prev, **play/pause — белая «печенька»**, next, repeat.
  - Громкость: толстый трек, вертикальный «штрих»-хэндл (слайдер MD3 Expressive).
- **Синхронный текст** (правая колонка): активная строка белая, со свечением и полупрозрачной пилюлей-подложкой; остальные ~40% непрозрачности; автопрокрутка, активная строка ближе к центру. Строки кликабельны (перемотка).
- **Визуализатор** (низ экрана): `Normal + Bars` — вертикальные пилюли от линии точек, зеркально от центра; `Normal + Wave` — сглаженная залитая область; `Circular` — радиальные полосы вокруг обложки. Цвет — из палитры обложки.

## Настройки (`screens/003.png`)

- Отдельное модальное окно (radius ~24) поверх Now Playing.
- Слева рейл: иконка + подпись (Visualizer, Background, Playback, Downloads, Appearance, About); выбранная иконка в круглом тональном контейнере.
- Контент: заголовок с иконкой; строки «подпись ↔ контрол». MD3 switch (primary), **connected button group** (Normal | Circular, Bars | Wave), слайдер с подписью значения (`120%`) и точкой-стопом на конце трека, поясняющий текст мелко.
- На фоне — размытые декоративные блобы.

## Что брать в наш клиент

| Элемент | Решение |
|---|---|
| Плавающие панели, рейл, пилюля-мини-плеер | берём, совпадает с выбранной раскладкой |
| Волнистые разделители и прогресс | берём (Canvas/Shape в QML) |
| Shape-морфинг (cookie, блоб-переход) | берём; реализация — SDF-шейдер (ShaderEffect) или интерполяция путей |
| Now Playing с блюром обложки и синхронным текстом | берём (MultiEffect blur) |
| Визуализатор | после MVP, выключен по умолчанию (PCM-тап mpv/PipeWire + FFT в numpy) |
| Акцент | **отличие от референса**: всё приложение перекрашивается под обложку текущего трека |
